มินิโปรเจกต์นี้เป็นการพัฒนาระบบการจองช่องจอดรถในลานจอดรถของบริษัทหนึ่ง ๆ สมมติว่าเป็นบริษัทให้บริการที่จอดรถซึ่งกระจายตัวอยู่ทั่วจังหวัดหรือทั่วประเทศ ระบบนี้พัฒนาขึ้นเพื่ออำนวยความสะดวกในการหาที่จอดรถของผู้คนที่มักจะหาได้ยากในเขตที่ประชากรมีจำนวนมากซึ่งทำให้ไม่มีที่จอดรถฟรีเพียงพอ ระบบนี้ใช้จองที่จอดรถล่วงหน้าและชำระเงินภายใต้เงื่อนไขที่บริษัทกำหนด

ประเภทซอฟแวร์ : Web Application เพราะว่าสะดวกสำหรับอุปกรณ์มือถือในการเข้าใช้งานเพราะเข้าใช้ผ่านบราวเซอร์ได้เลย ไม่ต้องติดตั้งแอปพลิชันลงอุปกรณ์

ขั้นตอนการทำงานเบื้องต้น(ลูกค้า)ของมินิโปรเจกต์นี้
1. ลูกค้าเข้าสู่ระบบ/สมัครสมาชิกผ่านเว็บไซต์
2. ลูกค้าค้นหาลานจอดรถและช่องจอดที่ว่างที่ต้องการ
3. ลูกค้าชำระค่ามัดจำจาก Digital Wallet ภายในบัญชีผุ้ใช้ที่เติมเงินเข้าไป
4. ลูกค้าได้รับการนำทางจากระบบมายังลานจอดและเจ้าหน้าที่ทำการสแกน QR Code ซึ่งเป็นหลักฐานการจองเพื่อยืนยันตัวตนเข้าลานจอด
5. เจ้าหน้าที่ได้รับข้อมูลการจองจากลูกค้าและอนุญาตให้ลูกค้าเข้าลานจอด
6. ลูกค้านำรถเข้าจอดและกด Check In
7. ระบบนำเวลาถอยหลังจนถึงเวลา Check out และเมื่อ Check out ตรงเวลาจะหักเงินที่เหลือ

เครื่องมือที่ใช้ในการพัฒนา
IDE: Visual Studio Code
Frontend: React
Backend: Node.js + Express.js
Database: PostgreSQL
Real Time: Socket.io
Authentication : JWT
Maps : Leaflet + OpenStreetMap
Financial : SCB API Sandbox

ฟีเจอร์เบื้องต้นสำหรับ User
- ✅การลงทะเบียนเข้าใช้  
- ✅การแสดงสถานะลานจอดรถ ณ สถานที่ต่าง ๆ ว่าว่างหรือไม่แบบ Real Time ด้วยแผนที่ Google Maps หรือ API Map ที่ฟรี
- ✅ระบบยืนยันตัวตนการเข้าใช้งานช่องจอดรถด้วย QR Code ด้วยการสแกน หรือการใส่ PIN ที่ได้รับ
- ✅ระบบการจับเวลาถอยหลังหลังจากการเข้าจอดรถ
- ✅ระบบการเก็บประวัติการใช้งาน
- ✅ระบบการนำทางไปสู่ลานจอดรถด้วย Google Maps 
- ✅ระบบการชำระเงินและระบบ Digital Wallet
- ✅ระบบจองคิวจอดรถในช่วงจอดที่มีคนกำลังใช้บริการอยู่
- ✅ระบบแจ้งเตือนล่วงหน้ากรณีมีช่องว่างในลานจอดรถหรือถึงคิวจอดรถแล้ว
- ✅การยกเลิกการจอง/การต่อคิว
- ✅การประเมินความพึงพอใจในการใช้บริการ

ฟีเจอร์เบื้องต้นสำหรับ Staff
- ✅การลงทะเบียนเข้าใช้
- ✅การตรวจสอบการเข้าใช้ช่องจอดรถด้วยการสแกน QR Code ของลูกค้าหรือกรอก PIN ของลูกค้าเพื่อตรวจสอบ
- ✅การแก้ไขสถานะช่องจอด
- ✅การเข้าถึงสถานะช่องจอดทั้งหมดในลานจอดรถที่รับผิดชอบ
- ✅การประกาศข้อความให้คนที่ใช้บริการในลานจอดของตัวเองรับทราบทั้งหมด

ฟีเจอร์เบื้องต้นสำหรับ Manager
- ✅การลงทะเบียนเข้าใช้
- ✅การเปิดปิดลานจอด
- ✅การกำหนดนโยบายการคิดเงินต่าง ๆ 
- ✅การเข้าถึงข้อมูลของ Staff 
- ✅การเขาถึงข้อมูลสารสนเทศหรือรายงานแบบ Real Time พร้อมผลการวิเคราะห์เบื้องต้นต่าง ๆ เช่น ข้อมูลการใช้บริการของลูกค้าและความพึงพอใจ

ฟีเจอร์เบื้องต้นสำหรับ Admin
- ✅การลงทะเบียนเข้าใช้
- ✅การกำหนดสิทธิ์ของผู้ใช้ระบบทุกคน
- ✅การจัดเก็บประวัติการใช้งานของผู้ใช้ทุกคน

Business Logic
- ลูกค้าจองพื้นที่ว่างได้ล่วงหน้าไม่เกิน 24 ชั่วโมง
- มาสายเกิน 20 นาทีแล้วปล่อยให้ช่องว่างทันทีและไม่คืนเงินมัดจำ
- การคิดเงินให้ผู้จัดการลานจอดเป็นผู้กำหนดตามความเหมาะสม
- ยกเลิกก่อนเวลา 1 ชั่วโมง คืนเงินมัดจำ
- การต่อคิวจะคิดเงินมัดจำรวมไปด้วยเลย
