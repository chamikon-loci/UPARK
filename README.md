# UPARK

My First Full Stack Project using PostgreSQL, Express.js, React.js, and Node.js.

UPARK is a web-based parking reservation system that allows users to manage their vehicles, find parking lots, reserve parking slots, and pay through a wallet system.

## Features

### User

* Register / Login
* Manage vehicle information
* View parking lots and parking slots
* Reserve a parking slot
* Pay reservation deposit through Wallet
* Cancel reservation and receive a refund
* View reservation history
* View parking history
* View transaction history
* Check current parking status

### Staff

* View assigned parking lots
* View parking slots
* Open / Close parking slots
* View reservations
* View currently parked vehicles
* Check In vehicles
* Check Out vehicles
* Calculate parking fees and overtime fees

This is my first Full Stack project, so the code and design may be a little rough.
There are probably many things that can be improved, but I built this project to learn how a Full Stack application works from Frontend to Backend and Database.
